# Motorola DSP56300 Backend

Omni provides native compiler backend support for 24-bit fixed-point digital signal processors, specifically targeting the **Motorola DSP56300 / DSP56311** family. This architecture powers iconic virtual-analog synthesizers including the Access Virus A/B/C/TI, Nord Modular G2, and Waldorf microQ.

With `--target:dsp56300`, Omni compiles `.omni` algorithms directly into clean-room, optimized Motorola DSP56300 assembly (`.asm`) ready for firmware integration, standalone DSP assemblers, and hardware emulators like [gearmulator](https://github.com/vitreo12/gearmulator) and Osirus.

---

## Architecture & Execution Model

The Motorola DSP56300 is a 24-bit fixed-point Harvard architecture processor with dedicated memory spaces:
- **X Memory**: Inputs, outputs, and default parameter values / uniforms.
- **Y Memory**: Persistent state variables, filter coefficients, and circular delay lines.
- **P Memory (P-RAM)**: Program code executing single-cycle ALU and MAC (Multiply-Accumulate) instructions.

### 24-bit Fixed-Point (Q23) Arithmetic

Values in the DSP56300 pipeline are represented in **Q23 two's complement fixed-point format**:
- **Word Width**: 24 bits.
- **Dynamic Range**: `[-1.0, +0.99999988]` ($1.0 - 2^{-23}$).
- **Accumulators**: 56 bits ($8 \text{ bits extension} + 24 \text{ bits high} + 24 \text{ bits low}$) with automatic saturation logic (`sat24`).

## Compiling for DSP56300

To generate Motorola DSP56300 assembly, invoke `omni` with `--target:dsp56300`:

```bash
# Generate Motorola DSP56300 assembly:
omni OmniSine.omni --target:dsp56300

# Specify output directory or custom file name:
omni OmniSine.omni --target:dsp56300 -o:./asm/ -n:OmniSine.asm
```

---

## Assembly Memory Layout

The generated assembly conforms strictly to standard Motorola DSP56300 syntax:

```assembly
; =============================================================================
; Motorola DSP56300 / DSP56311 Assembly generated by Omni compiler
; Module: OmniSine
; Target Architecture: 24-bit Fixed-Point DSP56300 / DSP56311 (Q23)
; Clean-room Motorola syntax: direct ORG P/X/Y mappings
; =============================================================================

; --- X Data Memory Map: Inputs, Outputs & Parameters ---
in1                          EQU     $0000
out1                         EQU     $0010
freq                         EQU     $0020

; --- Y Data Memory Map: State Variables & Scratch ---
phase                        EQU     $0000
freq_incr                    EQU     $0040

; --- Default Parameter Values in X Memory ---
                ORG     X:$0020
                DC      $0001B8         ; freq = 440.0

; --- Initial State Values in Y Memory ---
                ORG     Y:$0000
                DC      $000000         ; phase = 0.0

; =============================================================================
; Program Memory (P-RAM): Kernel Execution
; =============================================================================
                ORG     P:$0100
OmniSine_process:
                ...
                RTS
```

## Built-in Algorithms & Hardware Optimizations

- **Circular Ring Delay Buffers**: Hardware-accelerated circular ring buffer delays (modulo-64 with pointer wrapping) via `delay.read()` and `delay.write()`.
- **Hardware Saturation (`sat24`)**: Utilizes the 56-bit accumulator limiter and clamp intrinsics to guard against numeric overflow.
- **Restoring Shift-Subtract Division**: Genuine 24-bit variable division without requiring a floating-point unit.
- **Fast Polynomials**: Hardware-optimized polynomial approximations for `pow(2.0, x)`, `tan(x)`, `tanh(x)`, `sin(x)`, and `cos(x)`.
- **Power-of-Two Scaling**: Automatic bit-shift optimization (`ASL` / `ASR`) for multiplications and divisions by constant powers of two.
- **Dynamic Relocation (`compileOmniSnippet`)**: Direct emission of relocated assembly snippets with custom base addresses for embedding into host synthesis engines.
