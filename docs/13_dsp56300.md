# Motorola DSP56300 & C Backends

Omni provides native compiler backend support for 24-bit fixed-point digital signal processors, specifically targeting the **Motorola DSP56300 / DSP56311** family used in classic virtual-analog synthesizers (such as the Nord Modular G2, Access Virus, and Waldorf microQ).

In addition to DSP56300 assembly, Omni provides a clean-room C backend that translates Omni DSP modules into self-contained C99/C11 code suitable for native integration and WebAssembly (WASM).

---

## Architecture & Execution Model

The DSP56300 is a 24-bit fixed-point Harvard architecture processor with distinct memory spaces:
- **X Memory**: Inputs, outputs, and default parameter values.
- **Y Memory**: Persistent state variables, filter coefficients, and circular delay lines.
- **P Memory (P-RAM)**: Program code executing single-cycle ALU and MAC (Multiply-Accumulate) instructions.

### 24-bit Fixed-Point (Q23) Arithmetic

Values in the DSP56300 pipeline are represented in **Q23 two's complement fixed-point format**, where:
- Word width: 24 bits
- Value range: `[-1.0, +0.99999988]` ($1.0 - 2^{-23}$)
- Accumulators: 56 bits ($8 \text{ bits extension} + 24 \text{ bits high} + 24 \text{ bits low}$) with automatic saturation logic.

## Compiling for DSP56300

Omni provides two ways to generate DSP56300 assembly:

### 1. Dedicated `omnidsp` CLI Compiler

The `omnidsp` CLI tool compiles `.omni` or `.oi` source files directly into Motorola assembly (`.asm`) or C (`.c`):

```bash
# Generate Motorola DSP56300 assembly:
omnidsp OmniSine.omni -o OmniSine.asm

# Generate clean C99/C11 code:
omnidsp OmniSine.omni --target:c -o OmniSine.c
```

### 2. Standard `omni` CLI with Target Flag

You can also use the standard `omni` CLI:

```bash
# Generate DSP56300 assembly:
omni OmniSine.omni --target:dsp56300 -o OmniSine.asm

# Generate clean C:
omni OmniSine.omni --target:c -o OmniSine.c
```

## Assembly Memory Layout

The generated assembly conforms strictly to standard Motorola DSP56300 syntax:

```assembly
; =============================================================================
; Motorola DSP56300 / DSP56311 Assembly generated by Omni compiler
; Module: OmniSine
; Target Architecture: 24-bit Fixed-Point DSP56300 / DSP56311 (Q23)
; Clean-room Motorola syntax: direct ORG P/X/Y mappings
; =============================================================================

; --- X Data Memory Map: Inputs, Outputs & Parameters ---
in1                          EQU     $0000
out1                         EQU     $0010
freq                         EQU     $0020

; --- Y Data Memory Map: State Variables & Scratch ---
phase                        EQU     $0000
freq_incr                    EQU     $0040

; --- Default Parameter Values in X Memory ---
                ORG     X:$0020
                DC      $0001B8         ; freq = 440.0

; --- Initial State Values in Y Memory ---
                ORG     Y:$0000
                DC      $000000         ; phase = 0.0

; =============================================================================
; Program Memory (P-RAM): Kernel Execution
; =============================================================================
                ORG     P:$0100
OmniSine_process:
                ...
                RTS
```

## Built-in Algorithms & Features

- **Circular Ring Delay Buffers**: Hardware-accelerated circular ring buffer delays (modulo-64 with pointer wrapping) via `delay.read()` and `delay.write()`.
- **Restoring Shift-Subtract Division**: Real 24-bit variable division without hardware FPU.
- **Fast Polynomials**: Hardware-optimized polynomial approximations for `pow(2.0, x)`, `tan(x)`, `tanh(x)`, `sin(x)`, and `cos(x)`.
- **Power-of-Two Scaling**: Automatic bit-shift optimization (`ASL` / `ASR`) for multiplications by powers of two.
- **Dynamic Relocation (`compileOmniSnippet`)**: Direct emission of relocated assembly snippets with custom base addresses for embedding into host synthesis engines.
